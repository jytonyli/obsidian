✅ 为什么买万洲？
核心逻辑：滞胀环境下的高股息防御资产
  • 💰 8.5%股息率：远超10年美债（5.3%）和中国国债（1.68%），真实的"类债券"资产
  • 🥩 必需消费品：猪肉是刚需，经济衰退中需求稳定，现金流可预测
  • 🌍 全球分散化：美国Smithfield+中国双汇，两地业务对冲单一市场风险
  • 🐖 猪周期底部：美国猪价处于周期底部，产能去化后有望回升，利润弹性大
  • 📉 低估值：PE 7.5x，PB 1.1x，在消费股中估值偏低
  • 🔄 持续回购：管理层持续回购股票，支撑股价
❌ 什么时候卖万洲？
触发以下任一条件，减持或清仓：
  • 📉 股息率跌破5% → 股价大涨后股息率下降，估值吸引力消失
  • 🐖 美国猪周期见顶回落 → 周期高点卖出，不要持有到下行期
  • 💰 双汇分红率大幅下降 → 核心现金流来源出问题
  • 🏛️ 中美关系恶化影响业务 → 关税/贸易壁垒影响跨境业务
  • 📊 食品安全重大事件 → 品牌声誉受损，双汇业务受冲击
  • 📈 目标价到达HK$9-10 → 估值修复+周期上行完成，获利了结
