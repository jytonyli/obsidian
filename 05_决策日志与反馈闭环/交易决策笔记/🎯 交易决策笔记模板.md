# 🎯 交易决策笔记模板

> [!info] 页面状态
> 📅 最后更新：2026-09-08
> ⏰ 预计下次更新：按需触发（交易/复盘时）
> 🔄 如需更新：回复「更新 [[🎯 交易决策笔记模板]]」即可

> 每笔决策记录核心要素：**入场逻辑 + 可信度评估 + 事前验尸 + 止损信号**。
> *Dalio 原则：可信度加权决策 + 事前验尸防止盲目自信。*

## 📝 使用方法
1. 每次开仓前，复制此模板新建笔记，命名格式：`YYYY-MM-DD_标的_方向`
2. 必须在**入场前**写完，不做事后补录
3. 30 天后必须复盘，链接到 [[🔍 决策复盘模板]]
4. **可信度 < 5 分的决策不做**，或仓位减半


## 🎲 可信度加权评估（必填）

> *Dalio：不要对所有判断一视同仁，可信度高的判断权重更大。*

| 评估维度 | 评分（1-10） | 说明 |
|---|---|---|
| **我在这个领域的专业度** | /10 | 我是否深入研究过这个资产/行业？ |
| **证据质量** | /10 | 是硬数据还是主观判断？来源是否可靠？ |
| **与市场共识的差异** | /10 | 我的观点是否有充分的非共识依据？ |
| **历史胜率** | /10 | 过去类似判断的胜率如何？ |
| **时间窗口把握** | /10 | 我对催化剂发生时间的判断有多确定？ |
| **综合可信度** | **/10** | 取平均，<5分不做或减半仓 |

> 💡 *可信度 8+：可重仓（10–15%）；可信度 6–7：中等仓位（5–10%）；可信度 5：轻仓试探（<5%）；<5：不做。*

## ⏰ 30 天后必须回答
- 发生了什么 vs 我预期什么？
- 错的是阶段、传导，还是原则？
- 可信度评分是否准确？高可信度的决策是否真的胜率更高？
- 事前验尸中预测的失败原因是否发生？
- 下次怎么改？
