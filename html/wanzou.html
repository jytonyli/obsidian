🌡️ El Niño 对猪肉价格的传导路径

传导链：
El Niño（强厄尔尼诺）
→ 🌽 全球主产区干旱（美国玉米带、巴西大豆）
→ 🌽 玉米/大豆减产预期 → 粮价上涨（FAO食品价格指数三年新高）
→ 🐖 饲料成本上升（饲料占养殖成本60-70%）
→ 📉 养殖端利润受压 → 加速产能去化
→ 📈 长期：产能去化加速 → 下一轮猪周期上行更早到来 → 利好万洲2027年利润修复
💡 辩证看El Niño：短期（6个月）是利空——饲料成本上升压缩养殖利润。但长期（12-18个月）反而是利好——成本上升加速落后产能退出，让猪周期反转更早到来。万洲作为龙头，成本最低，在行业洗牌中反而受益。

✅ 为什么买万洲？
核心逻辑：滞胀/衰退环境的防御性底仓
  • 💰 9.3%+股息率：是中国10年国债利率的5.5倍，纯现金回报，股价跌就再投资
  • 🍖 必选消费刚需：猪肉是主食，经济好坏都要吃，穿越周期
  • 🌍 全球分散：中美两地业务，不押注单一国家周期
  • 📊 估值历史底部：PE 6.96倍，在港股消费股中最低，下行空间仅10-15%
  • 🔄 猪周期位置有利：中美猪周期都在底部，2027年有望迎来利润修复周期
  • 🛡️ Dalio框架匹配：通缩衰退环境的防御性资产，低配环境下也能有现金流
❌ 什么时候卖万洲？
触发以下任一条件，减持或清仓：
  • 💰 股息率跌破6%（股价涨到HK$10+）→ 估值不再有吸引力，高股息逻辑兑现
  • 📉 Smithfield连续2年利润下滑15%+ → 美国业务基本面恶化，不只是周期问题
  • 🏭 公司削减分红 → 高股息故事终结，核心逻辑破了
  • 📈 中国经济强劲复苏+利率上行 → 资金从高股息转向成长股，万洲跑输
  • 🍖 猪肉需求长期结构性下降 → 消费者转向其他蛋白，长期天花板压低
  • 🎯 目标价到达HK$9.5-10 → 估值修复完成，获利了结一半
