> 黄金定价的核心锚是**实际利率**。这是黄金投研的核心枢纽，所有关于黄金的判断最终都要回到实际利率的变化上。

## 核心公式

```
黄金价格 ≈ f(实际利率, 美元信用, 避险需求, 央行购金)
其中：实际利率是最核心、最稳定的解释变量
```

**实际利率 = 名义利率 - 通胀预期**

- 持有黄金的机会成本 = 实际利率（因为黄金不生息，持有黄金等于放弃了无风险利率的收益）
- 实际利率下降 → 持有黄金的机会成本下降 → 金价上涨
- 实际利率上升 → 持有黄金的机会成本上升 → 金价下跌

## 历史对应关系

| 时期 | 10年实际利率 | 金价 | 驱动逻辑 |
|---|---|---|---|
| 2008–2012 | 从 +2% 降到 -1% | 从 $800 涨到 $1900 | QE 推动实际利率暴跌 |
| 2013–2015 | 从 -1% 升到 +1% | 从 $1700 跌到 $1050 | 缩减恐慌，实际利率回升 |
| 2016–2018 | 从 0% 升到 +1% | 从 $1060 涨到 $1350 | 实际利率上行但通胀预期也上行 |
| 2019–2020 | 从 +0.5% 降到 -1% | 从 $1300 涨到 $2070 | 降息+QE，实际利率暴跌 |
| 2021–2022 | 从 -1% 升到 +1.5% | 从 $2070 跌到 $1620 | 美联储暴力加息 |
| 2023–2024 | 从 +1.5% 降到 +0.5% | 从 $1800 涨到 $2700+ | 降息预期+央行购金+地缘 |

**关键发现**：
- 2022 年实际利率飙升时，金价跌幅远小于模型预测（因为央行购金和地缘风险提供了支撑）
- 2023–2024 年实际利率仍在正值区间，但金价创新高，说明传统的实际利率框架需要加入"去美元化"和"央行购金"新变量

## 分析框架

### 第一步：判断实际利率方向
- **美联储政策**：加息周期 → 实际利率上行 → 利空黄金；降息周期 → 实际利率下行 → 利好黄金
- **通胀预期**：通胀预期上升 → 如果名义利率不跟上 → 实际利率下降 → 利好黄金
- **增长预期**：衰退预期 → 名义利率下降 > 通胀预期下降 → 实际利率下降 → 利好黄金

### 第二步：判断实际利率的"天花板"和"地板"
- 美国政府债务/GDP > 120%，利息支出/财政收入 > 15% → 实际利率很难长期维持在 +2% 以上（财政受不了）
- 实际利率的长期天花板可能在 +1.5%–+2%
- 实际利率的地板：如果通胀回归，实际利率可能再次转负

### 第三步：加入"新变量"修正
传统模型在 2022 年后失效，需要加入：
1. **央行购金**：每年 1000 吨+ 的央行购金，减少了可交易供给，提供了价格底部
2. **去美元化**：地缘冲突导致各国央行减少美债、增加黄金
3. **财政货币化担忧**：美国财政赤字失控，市场质疑美元信用
4. **地缘风险溢价**：俄乌、中东、台海，黄金的避险属性增强

### 第四步：得出结论
> [!判断]
> 当前实际利率 2.42% 处于历史 98 分位高位，按传统模型金价应承压，但金价仍维持在 4400 美元历史高位，说明传统框架已被"央行购金+去美元化+地缘风险"新变量打破。短期实际利率高位限制金价上行空间，但央行购金提供强支撑。若美联储转向降息（实际利率下行），金价有望突破上行。中期看多，短期高位震荡。

| 情景 | 实际利率路径 | 金价反应 | 概率 |
|---|---|---|---|
| 软着陆+缓慢降息 | 从 +1% 降到 0% | 温和上涨，$2500–$3000 | 40% |
| 衰退+快速降息 | 从 +1% 降到 -1% | 大幅上涨，$3000+ | 25% |

| 财政危机+美元信用受损 | 实际利率可能下降但美元暴跌 | 暴涨，$3500+ | 15% |
