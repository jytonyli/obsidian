## 🔥 场景一：通胀性繁荣（增长↑ + 通胀↑）— 过热

### 📝 经济特征
- 经济过热，需求强劲
- 通胀上行，央行可能加息
- 就业充分，薪资上涨

### 各资产预期表现

| 资产 | 预期收益 | 逻辑 |
|---|---|---|
| A 股 | +10%–+20% | 盈利增长，但估值受加息压制 |
| 美股 | +5%–+15% | 科技股可能跑赢价值股 |
| 港股 | +10%–+20% | 中国需求+美元流动性 |
| 中国债 | -2%–-5% | 利率上行，债券价格下跌 |
| 美债 | -3%–-8% | 美联储加息，长端跌幅大 |
| 黄金 | 0%–+10% | 通胀对冲，但实际利率上升压制 |
| 大宗商品 | +15%–+30% | 需求强+供给紧，戴维斯双击 |
| 现金 | +2%–+4% | 利率上行，货基收益提高 |

- 最佳策略：超配股票和商品，低配债券

- 关键指标：PMI > 52、CPI 上行、央行加息预期


## ⚠️ 场景三：通胀性衰退（增长↓ + 通胀↑）— 滞胀

### 📝 经济特征
- 经济停滞，但通胀高企
- 央行两难：加息伤增长，不加息通胀失控
- 通常由供给冲击引发（能源、粮食、供应链）

### 各资产预期表现

| 资产 | 预期收益 | 逻辑 |
|---|---|---|
| A 股 | -15%–-25% | 盈利下修+估值压缩，双杀 |
| 美股 | -10%–-20% | 估值杀，成长股跌幅大 |
| 港股 | -15%–-25% | 中国需求弱+美元流动性紧 |
| 中国债 | -2%–+2% | 增长弱支撑债市，但通胀压制 |
| 美债 | -5%–-10% | 通胀高，央行无法降息 |
| 黄金 | +15%–+30% | **最佳资产**，滞胀避风港 |
| 大宗商品 | +10%–+25% | 供给冲击主导，能源农产品强 |
| 现金 | +2%–+4% | 利率高，但实际收益为负 |

### 组合预期收益
- 目标组合：需用户自行计算（基于实际持仓权重加权）
- 最佳策略：超配黄金和商品，低配股票和债券
- 这是对传统 60/40 组合最不利的场景

### 发生概率
- 当前评估：25%（概率参考，需动态调整）
- 关键指标：PMI < 50、CPI > 4%、供给冲击


## 当前情景定位

> [!判断]
> 当前经济处于"通缩性繁荣"向"通胀性衰退"过渡的模糊地带：中国增长偏弱（Q2 GDP 4.3%，PMI 49.8）、通胀温和（CPI 0.5%）；美国增长温和但通胀粘性强（核心 PCE 3.3%），中东冲突推高油价（布油 98 美元）增加通胀风险。全球增长偏弱、通胀中枢高于疫情前。

- 当前象限：通缩性繁荣（增长偏弱+通胀温和），但有向通胀性衰退漂移的风险
- 增长相对预期：低于预期（中国偏弱，美国温和）
- 通胀相对预期：符合/略高于预期（美国粘性，中东油价风险）
- 6 个月后可能转向：取决于美联储政策和中东局势
