> 记录所有尚未被验证的投资假设。每个假设必须有明确的验证标准和时间窗口，避免变成"永远正确的废话"。

## 使用方法
1. 产生一个投资想法时，先写成可证伪的假设
2. 明确验证标准：什么数据/事件会证实或证伪
3. 设定时间窗口：多久内必须有结论
4. 验证后更新状态：已证实 / 已证伪 / 仍在观察
5. 已证实的假设可以升级为决策，已证伪的假设记录教训

## 假设质量检查
- [ ] 每个假设都是可证伪的（不是"中国经济长期向好"这种废话）
- [ ] 每个假设都有明确的验证标准
- [ ] 每个假设都有时间窗口
- [ ] 超过时间窗口未验证的假设，要么延长要么放弃
- [ ] 已证伪的假设记录了教训，不会重复犯
