## 核心关注
1. **收益率曲线控制（YCC）退出**：日银放弃 YCC 会导致日债收益率飙升 → 日本资金回流 → 全球资产抛售
2. **日元套利交易（carry trade）**：借日元买海外资产。日元快速升值时，套利交易平仓 → 全球风险资产承压
3. **通胀持续性**：日本经历 30 年通缩后，通胀是否真正回归
4. **工资增长**：春斗加薪幅度，是消费和通胀的关键
5. **日本央行持仓**：日银持有约 50% 国债，退出难度极大

## 对全球市场的传导
- 日银加息/退出 YCC → 日元升值 → 套利交易平仓 → 全球股票、债券抛售
- 日元贬值 → 套利交易活跃 → 全球流动性充裕 → 利好风险资产
- 日本通胀回归 → 日银正常化 → 全球利率中枢上移
